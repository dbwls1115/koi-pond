# 달밤 잉어 연못

연못을 눌러 잉어에게 먹이를 주고, 31가지 품종의 잉어를 키우며 이름을 지어 주는 웹페이지예요.

## 파일
- `index.html` — 웹사이트 전체 (이 파일 하나로 동작해요)
- `database.rules.json` — Firebase Realtime Database 보안 규칙

## 기능
- 연못을 클릭하면 먹이가 떨어지고, 꾹 누르고 있으면 계속 떨어져요
- 잉어를 누르면 이름을 지어 줄 수 있어요 (메뉴에서 잉어 터치를 끌 수 있어요)
- 잉어는 먹을수록 조금씩 자라요. 잉어 정보는 각자의 브라우저에 저장돼요
- 오른쪽 위에 다 같이 먹인 먹이 수와 지금 보는 사람 수가 나와요 (Firebase 설정이 들어간 뒤부터)

## 배포
Vercel에서 이 저장소를 가져와(Import) 배포하면 돼요. 빌드 설정은 필요 없어요.
