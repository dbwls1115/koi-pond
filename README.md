# 달밤 잉어 연못

연못을 눌러 잉어에게 먹이를 주고, 31가지 품종의 잉어를 키우며 이름을 지어 주는 웹페이지

## 파일
- `index.html` — 웹사이트 전체 (이 파일 하나로 동작)
- `database.rules.json` — Firebase Realtime Database 보안 규칙

## 기능
- 연못을 클릭하면 먹이가 떨어지고, 꾹 누르고 있으면 연속해서 먹이 주기 가능
- 잉어를 누르면 이름을 지어 줄 수 있음 (메뉴에서 잉어 터치를 끄기 가능)
- 먹이를 먹을수록 잉어 크기 변화 존재
- 잉어 정보는 각자의 브라우저에 저장
- 오른쪽 상단에 다 같이 먹인 먹이 수와 지금 보는 사람 수 표시
